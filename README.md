# Customer Purchase Prediction

This project focuses on predicting customer purchase behavior using machine learning.

## Objectives
- Predict whether a user will make a purchase
- Identify key factors influencing buying decisions

## Tools
- Python (Pandas, NumPy)
- Scikit-learn
- Google Colab

## Model
- Logistic Regression with feature scaling and class balancing

## Results
- Accuracy: ~93%
- Improved recall for positive class

## Key Insights
- User engagement (time spent, pages visited) strongly influences purchase decisions  
- Discounts significantly increase conversion probability  
- Behavioral data is more predictive than demographic data

- ## Project 2: Customer Churn Prediction

This project focuses on predicting customer churn using machine learning techniques.

### Highlights
- Handled imbalanced dataset
- Applied Random Forest classifier
- Tuned prediction threshold to improve recall
- Evaluated trade-off between precision and recall

### Results
- Accuracy: ~84%
- Improved recall for churn detection

### Key Insight
Detecting churn is more challenging than predicting non-churn customers, and optimizing recall is crucial for business impact.
